  reproduction and controlled replay.

  background tiers, cached projections, batched aggregates, instrumentation.

  the validator judges, the owning system mutates and emits events.

  explicit scheduling, reproducible scenarios.

- Presentation is read-only and parallel to simulation.
- Campaign owns geography and command hierarchy; no invented tactical orders.
- Cohesion != morale; organisational survival is campaign-side.
- Migration moves aggregated `PopulationCohort`s carrying information/history.
- `GovernmentType` is data; `Faction.government` is mutable.
- Playable != simulated; all factions are simulated.
- AD-2 (aggregate boundaries / concurrent action) and AD-3 (determinism depth)
  are **deliberately deferred** — this is intentional, not an oversight.

## 8. TheRev / Jev ownership (the corrected boundary)

```
HistoricalGame                      TheRev (external)
  canonical state                      provider registry
  knowledge filtering                  model manager / routing
  legal-action validation               credentials
  game-side intelligence seam  <---->  local + cloud runtimes
  deterministic fallback               Jev hosting
```

- HistoricalGame owns canonical state, permitted knowledge, filtered context and
  the legal-action gate, plus a **fallback path when no model is available**.
- TheRev owns provider registry, model management, routing, credentials,
  local/cloud runtimes and Jev hosting.
- `CharacterIntelligencePort` is **illustrative only** — name and API are not
  approved.
- Providers never receive omniscient state and never bypass validation.
- Recorded in: ADR-0012, A-35…A-40, `docs/architecture/system-dependency-graph.md`,
  `docs/domain/glossary.md`, `docs/README.md`, `README.md`, `ARCHITECTURE.md`,
