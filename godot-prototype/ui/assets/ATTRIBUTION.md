# Campaign interface artwork

All assets are local. The game makes no network requests for UI artwork.

## Pyrrhus of Epirus

- Original: `source/pyrrhus-marie-lan-nguyen.jpg`
- Display derivative: `pyrrhus-cutout.png`
- Photograph: **© Marie-Lan Nguyen (2011)**.
- Object: ancient marble portrait identified as Pyrrhus of Epirus, Naples National
  Archaeological Museum, inventory 6150, from the Villa of the Papyri, Herculaneum.
- Source: https://commons.wikimedia.org/wiki/File:Pyrrhus_MAN_Napoli_Inv6150_n02.jpg
- License: **Creative Commons Attribution 2.5 Generic (CC BY 2.5)**.
- License link: https://creativecommons.org/licenses/by/2.5/
- Changes: AI-assisted background extraction; runtime resizing, color treatment
  and architectural placement. The unmodified original photograph is retained.
  Extraction is a visual derivative, not an archaeological reconstruction.
- No endorsement by the photographer or museum is implied.

## Roman relief

- File: `source/suovetaurilia-marie-lan-nguyen.jpg`
- Photograph: **Marie-Lan Nguyen (January 2005)**, released by the photographer
  into the **public domain worldwide**, with an unrestricted-use fallback grant.
- Object: Roman marble Suovetaurilia relief, first half of the first century CE,
  Louvre, Ma 1096 (MR 852).
- Source: https://commons.wikimedia.org/wiki/File:Suovetaurile_Louvre.jpg
- Changes: runtime crop, desaturation, color treatment and edge fading.
- This is later Roman decorative artwork. It is not a representation of an event
  in 278 BCE or a new historical assertion about the campaign.

## Original decorative assets

`marble-command-frame.png`, `burgundy-damask.png`, `antique-icons.png` were generated
for this project using the built-in image generation tool. They are original
decorative artwork, not photographs of verified antiquities or copied game art.
The frame supplies carved marble cornices, pilasters and winged griffin endcaps.
Prompts are retained in `GENERATION-PROMPTS.md`. Source and display file hashes
are recorded in `asset-manifest.json`.

Attribution is also available inside Campaign menu → Artwork & licenses.
