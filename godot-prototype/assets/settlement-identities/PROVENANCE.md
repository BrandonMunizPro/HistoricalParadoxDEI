# Original Roman/Italic identity kit

Geometry is original project work in `settlement_identity_kit.gd`, extending the
existing original Roma mesh helpers. It comprises 18 primary stages with
near/far resources, six urban block variants with near/far resources, three rural
clusters with near/far resources and one crop tuft: 55 native meshes.

New textures are **White Plaster 02** (2K) and **Brown Mud** (1K), by Rob Tuytel
via Poly Haven. Six selected color/GL-normal/roughness maps total **9,407,123
bytes**. Both are CC0. Exact download URLs, authors, resolution, license links
and SHA-256 values are in `texture-manifest.json`.

- https://polyhaven.com/a/white_plaster_02
- https://polyhaven.com/a/brown_mud
- https://polyhaven.com/license

Other material channels reuse the preceding Roma showcase's CC0 terracotta,
stone, timber and path maps. Their original sources remain in
[`../roma-showcase/PROVENANCE.md`](../roma-showcase/PROVENANCE.md) and its manifests.
The stone surface combines the new limewashed albedo treatment with retained
stone relief; it is an art interpretation, not a scanned ancient wall.

Surrounding tree meshes retain the previously disclosed original generated
branch cutout. Its prompt, tool and file path remain in that provenance. No new
AI images were generated for this task. Crop geometry is original, not a scan.

Total War, DEI and Medieval Kingdoms images were studied only as references.
No proprietary mesh, texture, code or building-card image enters these assets.
The original oval arena is a game-design interpretation, not an exact replica
of the Colosseum; its timeline compression is explicit in the catalog. The
two settlements' layouts are illustrative compositions, not surveyed plans.

The main review and reference study distinguish implemented Roman assets from
planned cultural families. These materials and models have not been rolled out
worldwide. No asset purchase was made.
