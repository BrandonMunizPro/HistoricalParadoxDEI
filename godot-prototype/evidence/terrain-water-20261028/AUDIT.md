# Roma–Aricia terrain and water rendering audit

2026-10-28. Runtime inspection and native Godot screenshots, not an engine-capability judgment. This is a **review prototype**, enabled only by `--landscape-quality`. Settlement development, architecture, research and gameplay remain unchanged.

## Reference implementations actually inspected

- [Terrain3D material documentation](https://terrain3d.readthedocs.io/en/stable/docs/texture_painting.html), [actual shader](https://github.com/TokisanGames/Terrain3D/blob/main/src/shaders/main.glsl), [automatic slope material selection](https://github.com/TokisanGames/Terrain3D/blob/main/src/shaders/auto_shader.glsl), [performance documentation](https://github.com/TokisanGames/Terrain3D/blob/main/doc/docs/performance.md), [MIT license](https://github.com/TokisanGames/Terrain3D/blob/main/LICENSE.txt). Studied material channels, automatic distribution, clipmap controls and texture filtering/compression. Kept this project's geographic mesh pipeline; no plugin migration or claim that a Terrain3D demo was run on this machine.
- [Brandt-J Godot water shader source](https://github.com/Brandt-J/WaterShader/blob/main/Water.gdshader), [MIT license](https://github.com/Brandt-J/WaterShader/blob/main/LICENSE). Inspected inverse-projection depth reconstruction, absorption, screen texture use and animation. Original prototype shader uses the concepts with project units, existing river UVs and explicit time; no upstream shader pasted into runtime. Upstream code was inspected, not independently certified against Godot 4.7.2.
- [Godot depth reconstruction](https://docs.godotengine.org/en/stable/tutorials/shaders/advanced_postprocessing.html), [reverse-Z migration](https://godotengine.org/article/introducing-reverse-z/), [Image compression API](https://docs.godotengine.org/en/stable/classes/class_image.html). The implementation uses Vulkan depth 0..1 and inverse projection, not an obsolete hand-derived pre-4.3 depth formula.
- [Poly Haven license](https://polyhaven.com/license): selected photographs are CC0. [Copernicus DSM description/source](https://registry.opendata.aws/copernicus-dem/) and [GLO-30 license](https://documentation.dataspace.copernicus.eu/APIs/SentinelHub/Data/DEM/resources/license/License-COPDEM-30.pdf): free/open attribution terms, not CC0. Reference source snapshots are under `references/` with upstream MIT licenses. Working prototype compatibility is evidenced by **our actual native run logs/screens**, not by assuming every online shader works unchanged.

## Scoped implementation

1. Three actual albedo/normal/roughness sets: Sparse Grass (2K), reused Brown Mud (1K), Rocky Terrain 02 (2K). World-space material distribution uses smooth soil controls and terrain slope, triplanar exposed-ground colour and a Tiber bank distance field. OpenGL normal XY is stored in BC5 and Z reconstructed; albedo/roughness use S3TC. All have offline mipmaps, shared references and native resources, not repeated per-tile texture uploads.
2. The first tests demonstrated why metre-scale PBR alone is insufficient: distant surfaces averaged to brown, losing regional structure. Final review adds a filtered dual-scale colour macro from the existing CC0 Aerial Grass Rock photograph. This is broad colour variation, not gigantic literal grass blades. Existing local road/wear masks remain; the settlement ground shares the landscape base and retains its road response.
3. Aricia: additive 257² DEM patch, about 28×37 m resampling, from the same N41E12 COG through bounded range requests. The original Roma Gaussian treatment suppresses roof-scale spikes. Native ArrayMesh derivative reduces runtime mesh conversion work. Original parent/elevation/geography files are untouched; original 1.5× height and edge relationships are retained.
4. Tiber-area water: unchanged source XY, widths and rendered vertex positions; flow UVs, two advected original normal samples, depth-based absorption, slight screen refraction and a 2.5 m bank alpha transition. Flow sign is inferred from endpoint terrain elevation. Depth includes the existing 3 m ribbon lift and is **not bathymetry**. Standard dielectric sky/solar reflections are used; no planar reflections, SSR or expensive simulation. Ocean and lakes are unchanged.
5. Existing local tree proxies are scaled by .5 around their terrain-anchored instance origins inside the area, with a boundary fade. Both bark and leaves/shadows share this transform. Counts, species and meshes are unchanged. This corrects scale but **does not provide modern vegetation assets**.

The original failed candidates are retained. Candidate 1 had a shader scope compilation error and is invalid. Candidates 2–3 exposed missing mipmaps, aliased/poor colour controls and excessive normal-compression error. Candidate 4 corrected block artifacts. `after/` is an intermediate capture, **not the final selected review**. `review/` was aborted after an offline compression enum error; it is invalid. Use only `review-final/` for the final visual comparison.
